# Security & Ethical Policy

## Defensive Intent & Ethical Boundary

**DigitalShield** is developed strictly for academic forensic research, evidence integrity management, and victim defense against digital harm. 

The software contains no offensive exploitation vectors, vulnerability scanners, or credential harvesting capabilities. Any attempts to add features designed for surveillance, unauthorized data collection, or platform exploitation will be rejected.

---

## Reporting Vulnerabilities

If you discover a security issue or vulnerability in DigitalShield, please report it responsibly:

- Do **NOT** open a public GitHub issue for sensitive security vulnerabilities.
- Send a detailed vulnerability description to the project maintainers via secure email or private security reporting channels.
- Include steps to reproduce the issue and any potential impact assessments.

---

## Data Safety & Local Confidentiality

- All evidence files and case databases remain stored strictly on the user's local filesystem by default.
- API keys, credentials, or remote endpoints must be configured strictly through local OS environment variables.
